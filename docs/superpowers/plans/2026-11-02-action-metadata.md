# Тип «Бесплатно» и плашки действий

Утверждённый пользователем план реализуется в основной папке проекта; текущие незакоммиченные изменения сохраняются. Тип `free` / «Бесплатно» независим от ресурса и не меняет правила списания.

- Добавить `free` последним в choices и фильтр персонажа, создать миграцию choices без изменения существующих значений.
- Использовать общий шаблон метаданных в карточках, предпросмотрах, выборе персонажу и импорте: ◯ действие, △ бонусное действие, ✧ реакция, ▣ ресурс.
- Скрывать плашку типа для `free`, ресурса для `none`; при обоих значениях не оставлять отступов. В живом предпросмотре сохранять элементы и переключать `hidden`.
- Проверить 16 сочетаний, формы и ошибочный POST, группировку игрока, расход ресурсов, ZIP, Node и браузер на 1440/390 px. Обновить контракты.

Решения реализации: общий inclusion tag получает ключи, уровень и признак предпросмотра; клиент получает серверное сопоставление символов через экранированный data-атрибут. Категорийные значки меню/чата не меняются. Рабочая база не используется для тестов; commit и push не выполняются.
