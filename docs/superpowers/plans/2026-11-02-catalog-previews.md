# Соответствие предпросмотров настоящим карточкам

Согласованный подход: общие шаблоны полного содержимого карточки и краткого события для обычного просмотра и предпросмотра. Рабочая папка — `C:\dev\Dungeons-Kabans`, без отдельного worktree.

1. Добавить регрессионные проверки создания/редактирования всех видов каталога, текущей иконки, метаданных действия и повторного показа ошибочной формы.
2. Вынести полное содержимое карточки в общий шаблон; убрать краткий предпросмотр действий, сохранить краткие события и полные предпросмотры всех записей.
3. Брать значения предпросмотра из полей формы; сохранить символы `ϟ`, `◇`, формат уровня ячейки, безопасное обновление текста и PNG.
4. Обновить UI-контракт и проверки JavaScript; сравнить карточки и предпросмотры в Chrome на настольной и мобильной ширине.

Критерии: одинаковое оформление содержимого без управляющих кнопок в предпросмотре; корректные текущие/изменённые значения; отсутствие миграций и изменений API; сохранение предпросмотра персонажа.

Проверки: pytest, Django check, отсутствие миграций, JavaScript syntax/import bulk/catalog preview, браузерное сравнение и `git diff --check`. Данные браузерной проверки и снимки размещаются в игнорируемой `.browser-artifacts/catalog-previews/`; рабочая база не используется.
