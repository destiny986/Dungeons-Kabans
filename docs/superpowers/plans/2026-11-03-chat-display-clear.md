## Решения реализации

Подтверждение использует существующий `data-confirm` с необязательным `data-confirm-field`: поле получает `1` только на время подтверждённой отправки. Без JavaScript первый POST показывает `confirm.html`, второй подтверждённый POST выполняет очистку с тем же UUID.

Браузерная проверка выявила перекрывающиеся панели GridStack без JavaScript на настольной ширине. Для этого режима добавлено вертикальное расположение панелей: это делает кнопку и обычные формы доступными.

Миграции не нужны. Рабочая база не используется для проверок. Браузерная проверка создаёт отдельную БД внутри игнорируемой `.browser-artifacts/chat/`.
