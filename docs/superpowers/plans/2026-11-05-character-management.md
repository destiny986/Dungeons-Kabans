# Компактные карточки и копирование персонажей — план реализации

> Для реализации: superpowers:executing-plans, задачи последовательно в основной папке проекта.

**Цель:** компактные карточки управления с копированием и отзывом приглашений.
**Архитектура:** существующие Django-шаблоны, атомарный сервис операций и сервис
доступа; без новых зависимостей и миграций.
**Стек:** Python 3.12, Django 5.2, SQLite IMMEDIATE/WAL, локальные HTMX/CSS.
**Дизайн:** [согласованные требования](../specs/2026-11-05-character-management-design.md).

## Общие ограничения

Основная папка `C:\dev\Dungeons-Kabans`, без нового worktree. Рабочую базу,
секреты и vendor-файлы не менять. POST/CSRF и права через game.access.
Без копирования чатов/доступов и добавления операции в undo.
