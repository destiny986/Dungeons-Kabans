# Уведомление о повторной выдаче действия

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Показывать мастеру окно со списком персонажей, уже имеющих выдаваемое действие или заклинание.

**Architecture:** Сервис выдачи возвращает сохранённый снимок совпадений в успешном результате. HTTP-слой показывает его в существующем диалоге либо на полной странице без HTMX.

**Tech Stack:** Django templates, HTMX, SQLite.

**Spec:** Согласованный пользователем план в чате от 2026-11-03: уведомление после выдачи, одна кнопка «Понятно», остальные получатели получают действие как прежде.
