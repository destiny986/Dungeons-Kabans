# Компактные карточки управления персонажами

Согласовано с пользователем 5 ноября 2026 года.

## Результат

На странице управления портрет находится слева от центрированного столбца
«имя / класс / здоровье». Отступы вокруг текста и промежутки между строками
одинаковые, как в раскрытой карточке мастера. Статус остаётся сверху справа.
Ниже идут четыре нейтральные кнопки `button secondary small`: «Изменить»,
«Копировать», «Отозвать приглашение», «Удалить». Они занимают один ряд;
на узком экране подписи могут переноситься. Приглашение остаётся отдельной
кнопкой ниже. Другие карточки и предпросмотр редактора не меняются.

## Поведение

Копирование сразу создаёт полный независимый лист: характеристики, тексты,
портрет, здоровье, текущие/максимальные ресурсы, предметы с количеством,
изученные действия. Портрет использует существующий защищённый MediaAsset.
Новый персонаж находится вне игры, имеет новый UUID, начальную revision
и поколение приглашений. Чаты, доступы, приглашения и история не копируются.

Имя: `<основа> копия (N)`, минимальный свободный положительный N с учётом
нормализации. При копировании копии конечные суффиксы копии удаляются.
Основа сокращается для соблюдения лимита 30 символов; суффикс сохраняется.
Повтор UUID запроса не создаёт ещё одну копию. Копирование не входит в undo.
После успеха открывается полный список со всеми персонажами.

Отзыв повторяет существующее подтверждение и действие мастера: отзывает все
приглашения/браузерные доступы и переводит персонажа вне игры. Со страницы
управления возвращает на обновлённый список, сценарий мастера сохраняется.

## Подход и ограничения

Используются существующие атомарные операции, идемпотентность Operation,
сервис доступа и Django-шаблоны. Перенос через ZIP отвергнут как лишняя
обработка файлов для локального копирования. Новые зависимости и изменение
схемы БД не нужны. Работа выполняется в основной папке проекта.
